# Third-Party Notices

Add a notice for every third-party library, framework, tool, or code component included in the repository or release package.

For each component, record:
- Name and version.
- Author or project.
- Official project URL.
- License name and a copy/link to the license where required.
- Whether it is bundled, modified, or merely required separately.

Do not assume that a dependency is freely redistributable. Check its license before including its files in a public release.
