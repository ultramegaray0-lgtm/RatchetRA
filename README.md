# Ratchet & Clank: Rift Apart Randomizer

A gameplay randomizer project for the PC version of **Ratchet & Clank: Rift Apart**.

This repository is the source and transparency companion for the mod release. It is intended to provide source code, build guidance, installation documentation, and security information for users and reviewers.

> **Release status:** Source files and build details are being added. The repository is not yet a complete, independently buildable source release. Do not assume that the source or build instructions are complete until the relevant files have been uploaded and verified.

## What the project does

The randomizer changes aspects of the game's progression and item/reward distribution. The exact features, supported game version, compatibility notes, and known limitations should be documented here as the source release is finalized.

## Repository layout

- `SOURCE/Lua/` — runtime Lua source files.
- `SOURCE/DLL/` — source code for the compiled DLL component, if applicable.
- `SOURCE/Build/` — build scripts, project files, and reproducible build instructions.
- `DOCUMENTATION/` — installation, requirements, and build documentation.
- `SECURITY.md` — security and privacy notes.
