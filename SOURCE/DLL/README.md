# DLL Source

Upload the source code corresponding to the distributed DLL here, together with project/solution files and any required headers.

Also document:
- The DLL's purpose and runtime behavior.
- Compiler/toolchain and versions.
- Required dependencies and their licenses.
- Files and directories it reads or writes.
- Any network behavior (or explicitly confirm none after source review).
- Exact build steps in [Build Instructions](../../DOCUMENTATION/BUILD_INSTRUCTIONS.md).

Do not upload only the compiled DLL and describe it as source code. Do not include private keys, tokens, proprietary game files, or machine-specific build artifacts.
