# Mod uploads for review

Upload mod files here so they can be inspected for compatibility and installation issues.

## How to upload

1. Put the complete mod folder into a `.zip` archive (keep the original folder structure).
2. Open this folder in the repository on GitHub: https://github.com/ultramegaray0-lgtm/RatchetRA/tree/main/mod-uploads
3. Select **Add file → Upload files**.
4. Drag the ZIP file into the upload area, then select **Commit changes**.
5. Return to the chat and send the link to the uploaded ZIP or its commit.

## Before uploading

- Include the full Lua script folder and any accompanying manifest/config/readme files.
- Do not include game executables, personal files, passwords, API keys, or unrelated save files.
- If the archive exceeds GitHub's browser upload limit, split it into smaller ZIP files or use Git LFS/a GitHub Release instead.
- Keep the original filenames and directory structure; do not rename the mod files.
